# Avatok – Persönliche Website

Meine persönliche Website rund um Content Creation, Gaming, Technik, Community und ausgewählte Projekte.

🌐 **Live ansehen:** [avatok.github.io/Website](https://avatok.github.io/Website/index.html)

## Über das Projekt

Ich bin Pascal, online als **Avatok** bekannt, und komme aus Wien. Auf dieser Website stelle ich mich vor, verlinke meine Social-Media-Kanäle, meine Discord-Community und zeige Arbeiten aus den Bereichen Webentwicklung, Programmierung und Mediendesign.

## Inhalte

- **Startseite:** Kurze Vorstellung und Links zu meinen Kanälen
- **Über mich:** Interessen, Hintergrund und persönliche Werte
- **Social Media:** Twitch, Instagram, YouTube, GitHub und weitere Kanäle
- **Community:** Informationen und Einladung zum Discord-Server *Avocado Army*
- **Portfolio:** Projekte aus Webentwicklung, Programmierung, WordPress/WooCommerce und Mediendesign, einschließlich eigener Projektseiten
- **Rechtliches:** Impressum und Datenschutzerklärung

## Technologien

- HTML5
- CSS3 mit individuellem Avatok-Design
- [Bootstrap 5.3.3](https://getbootstrap.com/) für responsive Komponenten und Layouts
- JavaScript für interaktive Funktionen wie die Portfolio-Filter und die automatische Altersberechnung
- GitHub Pages für das Hosting

Das Design verwendet dunkle Hintergründe mit grünen und türkisfarbenen Akzenten. Bootstrap und die eigene `style.css` werden bewusst kombiniert, damit das individuelle Erscheinungsbild erhalten bleibt.

## Lokal starten

1. Repository herunterladen oder klonen.
2. `index.html` im Browser öffnen.
3. Für eine realistischere lokale Vorschau optional einen lokalen Webserver verwenden, beispielsweise mit der VS-Code-Erweiterung **Live Server**.

Für die über CDN eingebundenen Bibliotheken ist eine Internetverbindung erforderlich.
